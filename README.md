# INVO Ultimate v6.0

A research-only, paper-trading dashboard for BTC, ETH, SOL and JUP. No real-money trading is connected or approved. Historical tests, simulated trades and forward-return signal audits are experimental and are not evidence of reliable profits.

## Website
https://elikers.github.io/invo-ultimate/

## Publishing
Pushes to `main` trigger `.github/workflows/deploy.yml`. In repository **Settings → Pages**, choose **GitHub Actions** as the build and deployment source if prompted.

## Using the dashboard
Open the website in Chrome. The v6.0 consolidated audit and self-tests run in the browser; no downloads or API keys required. Data and cached audit results are stored in the browser and are not synced across devices.
